# Changelog

All notable changes to this project.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses
[semantic versioning](https://semver.org/spec/v2.0.0.html).

Note on dates: nothing here has a release date yet, because there are no releases yet. LittlePET is
pre-1.0 and the version in `package.json` tracks the milestone, not a published artifact.

## [Unreleased]

The M1 core engine. A cat sits on your desktop, watches your cursor with its eyes, and can be
picked up and shaken like mochi. Not yet released; not yet packaged.

Status per feature is tracked in [docs/PARITY.md](docs/PARITY.md), and every `done` row there names
an acceptance test that exists and passes.

### Added — engine

- **Stage window.** Transparent, always-on-top, `focusable: false`, click-through at rest, clamped to
  the display work area so the cat cannot be dragged out of reach.
- **Click-through hit test.** The cat is grabbed only where its pixels are opaque. The mask is the
  union across every frame, with 2-frame entry and 4-frame exit hysteresis so fast movement does not
  flicker.
- **Preload bridge.** `contextIsolation` + `sandbox`, four methods, no `ipcRenderer` exposed.
- **60 Hz snapshot channel.** A transferred `MessagePort`, not `invoke` round trips.
- **Input sampling.** Cursor position and smoothed speed, keystroke _rate_ over a 60-second ring of
  one-second buckets, scroll energy with framerate-independent decay.
- **Sprite pipeline.** Authored ASCII → indexed bytes → RGBA. Unknown characters throw rather than
  rendering as a hole. Eight pattern presets as pure data.
- **Animation clock.** Absolute elapsed time rather than accumulated deltas, so a walk cycle is
  identical at 60, 120 and 144 Hz.
- **Behavior priority machine.** Selection re-derived every frame; `minDuration` stops
  single-frame transitions. Priorities for ten reactions.
- **InputSampler + degraded mode.** The app runs without the native hook; only system-wide reactions
  are lost.
- **Mochi physics** — feature 03. Two volume-coupled springs plus a damped torsional wobble, fixed
  1/240 s sub-step.
- **Eye follow** — feature 02. Eased, clamped pupils that travel inside each frame's declared
  sockets. Sockets are 5×5 with a 3×3 sclera; the remainder is the travel budget.
- **Idle life.** Weighted director with cooldowns, self-grooming, wandering, sleeping after three
  minutes of quiet.
- **Multi-display.** Dragging tracks the work area of whichever display the cursor is on.
- **Settings store.** Atomic JSON writes; corrupt or hand-edited files start from defaults rather
  than refusing to launch. Config export/import (replacing M6 multi-device sync, feature 17).
- **Tray.** Show/hide and a reactions toggle. Degrades to nothing on a headless session.
- **App icons** generated from the same primitives as the cat, into `build/icon/`, never committed.

### Added — art

- **Nunu**, the base cat: 48×48, 19 frames across `idle`, `walk`, `dangle`, `stretch`, `groom`,
  `cheer`. Generated by `scripts/gen-cat.mjs` and committed as readable ASCII.
- **Procedural eye layer.** Sclera, travelling pupil, catchlight, blink lids, and expression glyphs
  drawn at runtime — so blinking and expressions cost nothing and work over every animation.
- **Terminal art review.** `npm run preview <anim>` prints frames as a shading ramp, so the art can
  be iterated on without an image viewer in the loop.

### Added — quality

- **135 unit tests** across sampler, animator, behavior machine, mochi physics, context and eye
  follow, sprite compiler, click-through, and the enforcement suite.
- **Enforcement tests** that keep the project's claims about itself true: no network in `src/`, no
  key content retained anywhere, asset provenance for every sprite, no parity row marked done
  without a passing test, and no wall clock in the renderer.
- **Asset audit** (`npm run assets:audit`), lint, Prettier, typecheck, esbuild bundler, Vitest,
  electron-builder config.

### Deliberately absent

Not gaps. Decisions, and they will not change without a very deliberate commit:

- No license key, payment, or device limit. MIT and free.
- No account, sign-in, telemetry, or crash reporting.
- No auto-updater.
- No network access of any kind.
