# Third-party notices

LittlePET itself is MIT licensed — see [LICENSE](LICENSE).

**As of the initial release there are no third-party assets in this repository.** Every pixel,
pattern and icon is authored or generated by a script in `scripts/`, and the app bundles no font
file: the UI uses the platform's system font stack.

That statement is enforced, not aspirational:

- `npm run assets:audit` ([`scripts/check-assets.mjs`](scripts/check-assets.mjs)) fails if any file
  under `src/` is a binary image, audio or font, or if any asset in
  [`docs/ASSETS.md`](docs/ASSETS.md) claims a license whose text is not reproduced below.
- `tests/unit/enforcement.test.ts` asserts the same properties in CI.

If a third-party asset is ever added, it must be listed in `docs/ASSETS.md` with its origin and
author, and its license text must be appended to this file. The audit will not pass until both are
done, so an uncredited asset cannot land.

## About the app this is modelled on

LittlePET is an independent reimplementation. It matches the _feature set_ and the _feel_ of a
commercially available desktop pet, and nothing else. No sprites, logo, name or copy were taken
from any other project — see [PLAN.md §0.1](PLAN.md) and
[docs/ASSETS.md](docs/ASSETS.md).
